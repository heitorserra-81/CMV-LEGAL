Manual do Usuário — CMV Legal v3
🛒 Vendas: Cada lanche exibe o hambúrguer desmontado em camadas. Toque em qualquer lugar do card para abrir a ficha técnica. Use +/− para registrar quantidades. Processe para baixar o estoque.
📦 Estoque: Toque na categoria → expande a lista → toque no insumo para abrir a ficha completa. Deslize para navegar entre insumos.
💰 Financeiro: Auditoria completa por insumo. Edite custo, contagem real e estoque mínimo direto no card. Todos os valores são exibidos em R$.
🧾 Ler Nota Fiscal: Use o botão na tela inicial ou no estoque. Escaneie o código de barras do produto; se já estiver cadastrado, informe a quantidade recebida e ela será adicionada às Compras. Se for um código novo, você pode cadastrá-lo na hora.
📊 Auditoria C1→C7: O sistema cruza Estoque Teórico (ini + compras − consumo) com a Contagem Real e exibe Divergência em Reais.
⚠️ Quebra: Registre perdas com motivo e data. O sistema desconta do estoque e alimenta o histórico.
