📚 Central de Ajuda

🤔 O que é CMV?

CMV (Custo da Mercadoria Vendida) é o valor total gasto com insumos para produzir os itens vendidos. Ex.: um X-Bacon leva 150g de carne, 50g de bacon, etc. O CMV total é a soma disso vezes as vendas.

📦 O que é divergência de estoque?

É a diferença entre o estoque teórico (quanto deveria ter) e o estoque final real (quanto sobrou). Divergência positiva = perda (desperdício, furto). Negativa = ganho (sobra).

🧮 Como o aplicativo calcula?

1. Você informa as vendas.
2. O app multiplica cada venda pela ficha técnica.
3. O consumo teórico é somado.
4. Estoque teórico = inicial + compras – consumo.
5. Divergência = estoque teórico – estoque final real.

✏️ Como preencher os campos?

- Vendas: digite quantas unidades foram vendidas.
- Estoque Inicial: quanto havia no início da semana.
- Compras: quanto foi comprado.
- Estoque Final Real: quanto sobrou após contagem.
